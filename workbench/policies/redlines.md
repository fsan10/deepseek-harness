# L3 红线：AI 永不执行，只生成工单转人工

以下动作无论在哪个视图、由谁发起，`workbench_control` 与任何新增工具都不得直接执行：

1. **付款与开票**：任何形式的资金出账、发票开具、红冲。
2. **删除与覆盖历史**：删除批次、删除 ODS 原始文件、改写已提交的结算结果。
3. **跨公司批量改价 / 批量分派**：影响面跨主体的批量写操作。
4. **权限变更**：新增角色、扩大他人授权范围、关闭审计。
5. **生产库结构变更**：DDL、TRUNCATE、全量刷新。

执行路径只有一条：`workbench_control` 返回 `blocked`，并在审计里留下一条待人工处理的工单线索；
人工在对应项目的原系统里操作，工作台不提供任何绕过入口。

## 为什么写死

L3 由财务与法务确认后才会调整。放进配置就一定会被配置改掉；
写进代码 + 审计留痕，才能保证「AI 不越权」不是一句口号。
