# 客服数据台 · 前端重构原型

本目录是「页面解耦 + 信息架构 + 日期规范 + 原型图」的交付物。**本轮只做设计，未修改 `app/`、`db/`、`automation/` 下的任何代码。**

- 在线画布：<https://ardot.tencent.com/file/739157683740041>
- 原型导出图：`prototypes/`（12 张，1.5x）
- 设计基线：2026-10-22，对应现有代码 `Dashboard.tsx` / `ReviewAnalytics.tsx` / `app/api/dashboard/route.ts`

## 一句话结论

现在不是「5 个页面」，而是**1 个 537 行组件里的 5 个条件渲染块**。重构的核心不是换视觉，而是按用户意图拆成 **8 个独立路由**，让每个页面只回答一个问题、只保留一个主操作，并把日期收敛成 **4 种形态、1 套北京时间规则**。

## 建议的确认顺序

1. **先确认信息架构**：8 个页面是否覆盖全部工作，是否有该合并/再拆的页面（重点看「差评分析 / 评价采集 / 采集设置」三拆）。
2. **再确认日期口径**：分析类「最近数据日」与采集类「不晚于昨天」是两种语义，不能混用。
3. **最后排实现**：先落共享壳与日期组件，再逐页迁移；迁移期间保留旧入口，避免一次性切换风险。

## 本轮未包含

- 高保真视觉稿与品牌延展（原型为中高保真结构稿）。
- 日期选择器的展开态逐帧设计（画布中给了收起态 + 预设，展开态沿用现有双月日历并补齐键盘操作）。
- 代码实现、接口改造、数据库变更。
- 移动端逐页稿（仅给出断点规则）。
