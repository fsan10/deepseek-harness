# 天猫推广费下载

## 前置条件

- 使用 profile `TMALL-天猫-MOCK旗舰店-财务账号`；从 note 获取平台、公司和店铺。
- 优先复用同一 Profile 的千牛与淘宝联盟登录态。已有联盟商家中心或“快速进入”确认页时原地继续；否则在千牛点击“推广→淘宝联盟”，接管同一浏览器上下文打开的标签页，并点击“快速进入”。不得跨 Profile 复制或输出 Cookie。
- 若联盟首页只有“立即登录”且没有内嵌表单，使用页面提供的主链接在同一标签页进入 `login.m.taobao.com` 的现有账号确认页，点击“快速进入”；返回联盟后若再次出现“快速进入”再确认一次。每个确认页只点击一次，不打开首页按钮产生的第二个登录弹窗，不切换账号。
- 只有现有会话不可用且出现真实内嵌密码表单时才回退账号密码登录，沿用 `--username`、`--password-env`；默认密码变量为项目未提交 `.env` 中的 `TMALL_LOGIN_PASSWORD`。不点击首页“立即登录”弹出第二个登录框，不读取或输出密码。
- 遇到 CAPTCHA、滑块、二次验证或需要人工账号授权时返回 `NEEDS_HUMAN`，保留当前 Profile，由用户完成验证后使用原命令续跑。

## 淘宝联盟推广费

1. 登录后打开 `https://ad.alimama.com/portal/v2/report/promotionDataPage.htm`。
2. 日报点击“昨日”。月报使用自定义日期：悬浮“自定义”按钮，点击“开始日期”输入框，输入 `YYYY-MM-DD` 后按 Enter；焦点会自动跳到“结束日期”输入框，再输入结束日期并按 Enter，最后点击“确定”。月报日期取上一个完整自然月。
3. 确认页面显示的统计起止日期与请求范围一致，再点击“下载报表”，选择“按店铺整体”，再确认。
4. 正常任务等待平台生成并自动下载。若提示“重复提交任务”，进入“下载记录”，下载最新一行可用任务。
5. 以日 `YYYYMMDD` 或月 `YYYYMM` 归档为“淘宝联盟推广费”；月报还要核对下载文件名或数据首尾日期确实落在目标月份。

## 万相台推广费

1. 复用淘宝联盟登录态打开万相台账户明细。
2. 时间类型必须选择“记账时间”（页面参数 `time=acount`，接口查询和导出参数 `timeType=acount`）。日报把 `cashStart`、`cashEnd` 设置为昨天；月报设置为上一个完整自然月的首日和末日。
3. 点击“下载数据”，捕获下载后归档为“万相台推广费”。

## 执行与验收

- 使用 `tmall_taobao_union_promotion_download.py` 或 `tmall_wanxiangtai_promotion_download.py`，传入本次 profile 的 `--cdp`、平台、公司、店铺和 `--mode day|month`。
- 目标目录分别为 `C:\Users\win\Desktop\data\天猫\淘宝联盟推广费`、`C:\Users\win\Desktop\data\天猫\万相台推广费`；文件必须存在且非空。
- 月度批量下载按“淘宝联盟→万相台”串行执行，共用同一财务 profile 的 wsEndpoint；`--mode month` 表示上一个完整自然月，不使用平台当前月份默认值。
- 失败时连接同一 CDP，检查当前 URL、可见弹窗、下载记录和首行可用下载按钮，修复后完整重跑。
- 完成后关闭本次启动的 profile。
