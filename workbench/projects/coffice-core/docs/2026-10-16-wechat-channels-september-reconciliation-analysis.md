## 1. 系统口径（as implemented）

**链路**：视频号结算动账流水（平台导出文件，原样入 ODS）→ DWD 按"收支类型"把金额拆入 `income_amount` / `expense_amount` → DWS 按"记账日期 + 动帐类型"日汇总 → ADS 加公司维度。**统计日期一律取 `记账时间`**。

### 1.1 结算口径（结算收入 / 结算支出 / 结算净额）

全量如实拆分，不丢任何流水：

```text
收入 = 收支类型为"收入"的金额：订单支付 + 订单交易｜先用后付 + 极速退款垫资 + 平台优惠补贴
支出 = 收支类型为"支出"的金额：订单退款 + 达人佣金 + 技术服务费 + 带货机构服务费
                              + 回补极速退款垫资 + 平台优惠补贴（冲回）
结算净额 = 收入 − 支出
```

### 1.2 主营口径（主营业务收入 / 平台费用，财务看板用）

```text
商品销售收入 = 订单支付 + 订单交易｜先用后付
平台补贴     = 平台优惠补贴净额（收入 − 冲回）
销售退款     = −订单退款
主营业务收入 = 商品销售收入 + 平台补贴 + 销售退款
平台费用     = 达人佣金 + 带货机构服务费 + 技术服务费 + 运费险
```

- 提现、极速退款垫资、回补极速退款垫资：保留映射，**不计入主营收支**，只作资金勾稽（延续 2026 年 5 月验收确定的口径）。
- 达人佣金一级分类 = 达人佣金 + 带货机构服务费（合并展示）。

### 1.3 极速退款垫资 / 回补垫资的资金机制（平台官方口径）

微信小店官方《货款资金对账》操作指南对"极速退款"资金流的说明：

> 用户满足条件并触发极速退款，由平台为商家进行垫资：平台将售后单退款金额**垫付到商家货款账户**中，再从商家货款账户将该售后单的退款金额**退还给用户**，后续再从商家账户中**扣回平台垫付的金额**。

对应到资金流水（以 9 月真实订单 `3738746859623187201` 为例）：

| 时间 | 流水 | 收/支 | 金额 | 说明 |
|---|---|---|---:|---|
| 08-27 | 订单支付 | 收入 | +198.00 | 用户货款进入商家货款账户（冻结/待结算） |
| 09-02 | 极速退款垫资 | 收入 | +198.00 | 平台垫付退款金额到商家货款账户 |
| 09-02 | 订单退款 | 支出 | −198.00 | 从商家货款账户退款给用户 |
| 09-04 | 回补极速退款垫资 | 支出 | −198.00 | 平台从商家账户扣回垫款 |

- 四笔合计 **0**：垫资与回补**按订单号一一配对、金额相同、间隔 1~3 天（多数 2 天）**（全表 11 对全部配平）；商家不因垫资多付一分钱，垫资只是平台的"过桥"资金。
- 因此系统对这两类流水只做资金勾稽，不计入主营收支（在结算收支里它们如实保留为收/支流水的一部分）。

参考：微信小店《货款资金对账》操作指南（商家版）、开放平台"获取资金流水详情"接口枚举（`14 极速退款垫资` / `15 回补极速退款垫资`）。
