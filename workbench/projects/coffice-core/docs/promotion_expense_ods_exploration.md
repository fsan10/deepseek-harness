# 七平台推广费指标口径与 ODS 探查报告

## 1. 业务目标与最终口径

- 指标编码：`promotion_expense`
- 指标名称：推广费
- 平台范围：抖音、拼多多、京东、天猫、快手、视频号（微信小店）、小红书。
- 业务定义：抖音、拼多多、京东、天猫按已确认的广告或推广来源汇总支出为正的推广费用；当前没有推广费来源的快手、视频号、小红书只在ADS按日补零，供DataEase公共筛选器关联。
- 展示：一张推广费指标卡和一张按日、按平台分系列的趋势折线图。
- ADS粒度：统计日期、平台、公司、店铺；支持公司、店铺、平台和日期公共筛选器。

## 6. 展示维度与风险

- `stat_date`：全部来源覆盖，适合日趋势折线图。
- `platform_code/platform_name`：七个平台覆盖，适合作为趋势系列和平台筛选器；快手、视频号、小红书当前系列值均为0。
- `company_code/company_name`：通过`batch_id -> common.v_ingest_batch_shop_context -> DIM`按统计日期匹配，当前覆盖率100%。
- `shop_code/shop_name`：通过批次标准店铺获得，当前覆盖率100%，为后续多店铺导入预留。
- 来源渠道只保留在平台DWD/DWS中用于财务核对；当前ADS服务指标卡和平台趋势，不增加第二张渠道构成图。
- 旧版`.xls`需要`xlrd`；通用Loader已增加该格式支持。
