- 店铺：`123572735 / MOCK饮品旗舰店`
- 结算来源：`京东6月结算单.csv`
- 资金来源：`京东资金6月.csv`


## 5. 明确排除但保留映射的场景

| 原始场景 | 处理 |
| --- | --- |
| 结算单货款 | 进入主营业务收入或销售退款，不计平台费用 |
| 资金单商户结算 | 结算单净额进入钱包的重复事实，只用于跨日对账 |
| 资金单售后退款质保金扣除 | 进入销售退款并跨表去重，不计平台费用 |
| 结算单代收配送费 | 代收性质，当前不计平台费用 |

`综合违约金`已建立一级分类“违约金”映射；本次6月文件没有该费用，历史数据存在时会按映射纳入。

## 7. 每日统计规则

| 来源与场景 | 业务统计日期 | 是否进入主营收支 |
| --- | --- | --- |
| 结算单订单货款 | 账单日期 | 主营业务收入 |
| 结算单退款货款 | 账单日期 | 主营业务收入冲减 |
| 结算单佣金、保险、服务费等 | 账单日期 | 主营业务支出 |
| 资金售后退款质保金扣除 | 入账日期 | 主营业务收入冲减 |
| 资金联盟扣款/补款、消费订单、直赔、保险理赔 | 入账日期 | 主营业务支出或冲减 |
| 资金商户结算 | 关联结算单账单日期 | 不计指标，仅对账 |

收入ADS和支出ADS均覆盖2026年6月1日至6月30日共30个自然日。收入没有业务事件的日期写入0值占位，保证DataEase日趋势不断点。
