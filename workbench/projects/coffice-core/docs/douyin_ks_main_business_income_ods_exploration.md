```text

+ 银行补贴
+ 以旧换新抵扣

```

- `收入合计`与十项组成的汇总差额为`0.00`；
- 不一致记录数为`0`；
- 结算后退款已由平台生成负收入记录，不再读取资金单重复冲减。

## 4. 快手字段与公式核验

按用户确认，快手主营业务收入公式为：

```text
订单实付(元)
+ 政府补贴
+ 支付营销补贴
+ 平台补贴
+ 达人补贴
- 商家补贴(元)
- 订单退款(元)
- 资金单未在结算单体现的超售后期实际退款扣减
```

`合计收入(元)`未扣除`订单退款(元)`，因此不能直接作为主营业务收入。
当前`商家补贴(元)`和`政府补贴`均为0，但字段仍需保留以支持后续数据。
