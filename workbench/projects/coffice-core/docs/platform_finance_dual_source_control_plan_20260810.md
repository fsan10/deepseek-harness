# 七平台结算单与资金单混合取数防重方案

制定日期：2026-08-10  
适用指标：`main_business_income`（主营业务收入）、`platform_expense`（平台费用/主营业务支出）  
操作边界：保留全部 ODS 原始数据；不以修改、删除或覆盖 ODS 的方式修正指标；本次实施只使用数据库现有数据，不导入桌面样本。

## 1. 目标

结算单负责解释订单收入、退款及结算费用组成，资金单负责记录钱包实际动账和结算单没有的经营事项。两张单据可以同时保留，但同一业务事实只能进入指标一次。

本方案以三个约束避免混乱：

1. 每个平台、每类业务事件都必须指定唯一的来源职责。
2. 结算到账、提现、冻结解冻等资金变化与经营指标分开，不因出入账方向直接认定为收入或费用。
3. 主营业务收入和平台费用先在各平台 DWS 完成来源选择、去重和符号处理，ADS 只做七平台汇总和公司映射。

## 2. 来源职责

| 编码 | 含义 | 是否进入主营收支 |
|---|---|:---:|
| `PRIMARY` | 该业务组成的唯一主计算来源 | 是 |
| `SUPPLEMENT` | 主来源没有记录的额外经营事项 | 是 |
| `EXPENSE_OFFSET` | 费用返还、补款、理赔等费用冲减 | 是，按负费用 |
| `REFUND_SUPPLEMENT` | 结算单没有记录的结算后退款 | 是，跨表查重后冲减收入 |
| `RECONCILIATION` | 结算到账、退款资金过程、冻结解冻等勾稽流水 | 否 |
| `ACCOUNT_TRANSFER` | 提现、充值、保证金或广告账户划转 | 否 |
| `DUPLICATE` | 已在另一主来源确认的同一业务事实 | 否 |
| `UNMAPPED` | 新出现且尚未确认职责的场景 | 否，阻断刷新 |

费用映射同时保留计算角色：

- `MAIN_REVENUE`：商品销售收入、平台补贴。
- `MAIN_REFUND`：销售退款，金额为负。
- `PLATFORM_EXPENSE`：正常费用，金额为正。
- `EXPENSE_OFFSET`：费用冲减，金额为负。
- `RECONCILIATION`、`ACCOUNT_TRANSFER`、`EXCLUDE`：不进入主营收支。

抖音资金单虽然包含部分结算费用组成字段，本次为保证当前 ADS 逐日、逐分类和来源类型完全一致，继续采用“结算组件为主、资金独有场景补充”的已验证策略。后续若切换为资金组件主来源，必须按店铺和覆盖期间建立来源锁，并先证明与结算组件逐日逐分类完全等价；同一店铺同一期间不得同时启用两套完整组件。

## 4. 去重优先级

按以下顺序识别同一业务事实：

1. 平台唯一流水号、单据编号。
2. 订单号、售后单号、退款单号。
3. 结算批次号或商户订单号。
4. 订单号 + 原始费用场景 + 金额。
5. 没有可靠共享键时，通过平台来源职责强制互斥，不使用“日期 + 金额”猜测去重。

当前重点规则：

- 京东、快手资金补充退款必须先检查结算单是否已有同订单退款；已有则资金流水只作勾稽。
- 京东结算单按单据编号选最新版本，资金单按钱包业务事件组合键选最新版本。
- 天猫聚合账户按支付流水号、支付宝账户按账务流水号选最新版本。
- 拼多多和视频号只保留当前规范账务明细这一份事实，不再叠加另一个同义文件。

## 5. 日期与金额规则

- 结算业务事件使用平台结算/账单/记账日期。
- 资金单独有的经营事项使用资金实际动账日期。
- 商户结算到账保留资金日期用于现金流和对账，但不进入主营业务收入或平台费用。
- 不对整个资金单统一减一天。
- 主营业务收入：销售及补贴为正，退款为负。
- 平台费用：扣款为正费用，返还、补款、理赔为负费用。

## 6. 实施控制

1. 在 `dim.dim_platform_fee_mapping` 增加系统维护的 `source_role`、`metric_role` 和 `dedup_rule_code`。
2. 一级、二级费用分类继续由财务维护；系统来源职责不得覆盖财务分类名称。
3. 平台费用 DWS 只允许 `PRIMARY`、`SUPPLEMENT`、`EXPENSE_OFFSET` 角色且 `include_in_platform_expense=true` 的场景进入计算。
4. `UNMAPPED` 或“计入费用但职责不允许”的映射必须阻断刷新。
5. 现有 DWD 保留所有候选来源和原始追溯字段；排除不等于删除原始事实。
6. 七个平台继续分别在各自 DWD/DWS 实现规则，共享 ADS 不写平台特有判断。

## 8. 验收关卡

1. 129 条当前有效费用映射全部具有明确来源职责，无 `UNMAPPED`。
2. 91 条计入费用映射的职责只能是 `PRIMARY`、`SUPPLEMENT` 或 `EXPENSE_OFFSET`。
3. 七个平台 DWS 到共享 ADS 双向金额差异为 0，公司未匹配为 0。
4. 主营业务收入 ADS 和平台费用 ADS 的逐平台行数、日期、金额及有序行摘要与第 7 节完全一致。
5. 连续刷新两次结果一致。
6. 至少抽查正常费用、费用返还、结算后退款、结算到账和账户划转五类场景。
