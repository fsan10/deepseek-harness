# 拼多多、视频号、小红书主营业务收入与平台费用 ODS 探查报告

## 1. 业务目标

本轮使用当前数据库中已经导入的 2026 年 5 月结算数据，为拼多多、视频号和小红书建立：

- 主营业务收入：订单相关收入减销售退款；
- 主营业务支出：结算单中的平台经营费用，正常扣费为正、退回或补回为负；
- 收入明细：商品销售收入、平台补贴和销售退款；
- 支出明细：平台原始二级分类映射到财务人工维护的一级分类。

提现、账户内部转账和极速退款垫资勾稽不属于平台费用，保留映射但不进入指标。

## 3. 最终口径

### 3.1 拼多多

统计日期取`发生时间`。

```text
商品销售收入 = 交易收入-订单收入 + 交易收入-优惠券结算
销售退款 = 交易退款-订单退款 + 交易退款-优惠券结算
主营业务收入 = 商品销售收入 + 销售退款

平台费用 = 除收入、退款、提现、转账广告账户以外的全部结算流水取反
```

二级分类固定为`账务类型 + 业务描述`。提现 184,000.00 元和转账广告账户 83,210.00 元只作资金去向审计，不计平台费用。

### 3.2 视频号

统计日期取`记账时间`。

```text
商品销售收入 = 订单支付 + 订单交易｜先用后付
平台补贴 = 平台优惠补贴收入 - 平台优惠补贴支出
销售退款 = -订单退款
主营业务收入 = 商品销售收入 + 平台补贴 + 销售退款

平台费用 = 达人佣金 + 带货机构服务费 + 技术服务费 + 运费险
```

### 3.3 小红书

收入和费用统计日期均取`结算时间`。

订单结算源表的`动账金额`已经扣除了平台佣金、买手佣金和花呗分期手续费。因此主营业务收入按每条事件还原佣金前金额：

```text
收入事件金额
  = 动账金额 - 平台佣金 - 买手佣金 - 花呗分期手续费

平台费用
  = -平台佣金
  + -买手佣金
  + -花呗分期手续费
  + -其他服务款动账金额
```

该公式按源动账金额精确勾稽。使用商品实付、补贴和佣金组成字段逐行重算时有一条 0.01 元四舍五入差异，因此组成字段只作审计，不替代源动账金额。

## 4. 费用一级分类建议

| 平台原始场景 | 建议一级分类 |
| --- | --- |
| 平台佣金、技术服务费、消费者体验提升计划 | 平台服务费或平台佣金 |
| 买手佣金、达人佣金、带货机构服务费 | 达人佣金 |
| 多多进宝、多单立减 | 推广费 |
| 运费险、运费补偿、运费宝 | 退货物流费用或运费保险 |
| 小额打款、售后补偿消费者 | 小额打款或售后赔付 |
| 虚假发货、延迟发货 | 违约金 |
| 分账支出 | 其他平台费用 |

种子映射只提供当前建议，不覆盖财务后续人工维护。

## 5. DataEase设计

- 主营业务收入指标卡：共享收入 ADS 汇总`income_amount`。
- 平台总费用指标卡：共享费用 ADS 汇总`expense_amount`。
- 收入明细：`primary_category_name -> secondary_category_name`。
- 费用明细：`primary_category_name -> secondary_category_name`。
- 日趋势：`stat_date`为横轴，平台或一级分类为系列。
- 公共筛选器：公司、日期、平台、店铺。

ADS 粒度均为：

```text
stat_date + company + platform + shop
+ primary_category + secondary_category + source_document_type
```

## 6. 风险与后续数据

- 拼多多“转账-广告账户”是账户资金划转，不代表当日真实广告消耗，本轮不计平台费用。
- 视频号极速退款垫资与回补存在 188.00 元时点差，只作资金勾稽，不计收入或费用。
- 小红书新月份如果新增费用组成字段或其他服务款，费用映射完整性校验会阻断刷新，要求财务先完成一级分类。
- 后续导入 6 月数据时必须使用相同 ODS Loader 并显式传入标准`shop_code`，不得覆盖 5 月数据。
