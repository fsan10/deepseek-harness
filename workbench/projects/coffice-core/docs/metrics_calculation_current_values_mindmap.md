- 订单与销售
  - GSV
    - 当前值：1,290,519.27 元
    - 数据日期：2026-06-01 至 2026-07-05
    - 最新统计日：2026-07-05
      - 当日值：113,702.27 元
    - 通用计算
      - 各平台先按照独立订单有效性口径计算店铺日 GSV
      - ADS 再按日期、平台、公司和店铺汇总
    - 抖音
      - 公式：订单应付金额 + 优惠总金额 - 商家实际承担优惠金额
      - 仅纳入订单状态为“已发货”或“已完成”的订单
      - 排除待收退货、待退货、售后待处理和退款成功等售后状态
    - 天猫
      - 公式：买家实付金额
      - 排除订单状态为“交易关闭”的订单
      - 退款状态排除“退款成功”
      - 排除商品标题包含“购物金”的商品行
    - 京东
      - 公式：订单应付金额
      - 排除订单状态以“(删除)”开头的订单
    - 快手
      - 公式：订单实付款
      - 排除订单状态为“交易关闭”的商品行
      - 排除售后状态为“退款成功”的商品行
    - 拼多多
      - 公式：商家实收金额
      - 仅纳入“已发货，待收货”和“已收货”订单
      - 仅纳入“无售后或售后取消”
    - 视频号
      - 公式：订单实际收款金额
      - 仅纳入已完成订单
      - 排除存在“退货退款完成”或“退款完成”售后的订单
    - 小红书
      - 公式：商家应收金额（支付金额）
      - 仅纳入订单状态为“已完成”的 SKU 商品行
      - 仅纳入售后状态为“无售后”的 SKU 商品行
