# 抖音运营各产品GMV占比 ODS 指标探查报告

## 1. 业务目标

- 平台：抖音。
- 指标：运营各产品销售额GMV占比。
- 目标：不再使用平台商品ID和选购商品名称作为产品维度，改为通过订单`商家编码`映射公司的统一大产品分类与产品名称。
- 金额口径沿用已确认的抖音运营GMV：非刷单主订单范围内，每个子订单行直接取`商品单价`，不乘商品数量、不扣商家补贴、不筛订单状态或售后状态。
- 刷单口径沿用现有指标：主订单任一子行`订单应付金额 >= 2000`时整单排除。

## 3. 字段映射与清洗

| 业务字段 | 来源 | 清洗与使用规则 |
| --- | --- | --- |
| 大产品分类 | 产品编码表`一级分类` | 每行完整维护一级分类，不再依赖合并单元格继承。 |
| 二级分类 | 产品编码表`产品分类（二级）` | 达播看板的主要产品分类展示层级。 |
| 产品名称 | 产品编码表`产品名称` | 每行产品与商家编码一一对应；盒装、小袋或试喝装可使用独立产品名称。 |
| 商家编码模式 | 产品编码表`盒装对应编码` | 提取并清理首尾空格；末尾`X`表示数量通配符，如`M-NXSY-X`匹配`M-NXSY-2`。名称含“小袋/试喝”的末尾`-1`按数量通配处理。 |
| 订单商家编码 | ODS`商家编码` | 按半角或全角加号拆为有序组件；当前19,405行均非空。 |
| 组件权重 | 商家编码末尾数量 | 组合装按各付费组件编码数量占比分摊整行`商品单价`。 |
| GMV | ODS`商品单价` | 严格数字清洗后直接作为整行GMV，不乘`商品数量`。当前数值解析失败0行。 |
| 赠品识别 | ODS`商品规格`与有序商家编码 | 正GMV行的赠品可能与付费品共用一行，不能仅凭整行GMV是否为0判断。规格含“赠”时，按规格顺序仅保留“赠”字前对应的前N个商家编码组件，后续组件标记为赠品且不参与分摊；零GMV整行不生成产品销售额。 |
| 未映射兜底 | 商家编码组件 | 当前通过数量通配后全部命中。未来未命中编码进入`未映射/未映射产品`，保留GMV并由ETL报警，不静默丢失。 |

## 4. 组合装与赠品实测

- 商家编码共51种，4,917行包含组合编码。
- 组件数分布：单组件14,488行、双组件4,755行、三组件122行、四组件40行。
- 产品编码表共抽取35个编码模式、35个一对一公司产品记录。
- 将小袋末尾数量作为通配符后，19,405个非刷单子订单全部完成映射。
- 10,268个零GMV行不产生产品销售额；9,137个正GMV行进入产品分摊。
- 447行商品名称或规格含赠品描述；其中411个正GMV行实际混入613个赠品编码组件，已按规格顺序规则排除。
- 36个凤梨美式订单规格描述了未列入商家编码的随机薄脆赠品；商家编码只有付费凤梨美式，因此无需额外扣减。

示例订单`6954244409346365284`：

| 商家编码 | 公司产品 | 权重 | 分摊GMV |
| --- | --- | ---: | ---: |
| `M-NXSY-2` | 糯香生椰拿铁 | 2 | 99.00 |
| `M-MLXY-2` | 茉莉雪芽拿铁 | 2 | 99.00 |

该主订单另有一条`M-MLXY-1`零GMV赠品子订单，产品销售额不纳入。

## 5. 日期、状态、退款与金额候选

- 日期不新增候选，沿用已确认的`DATE(订单提交时间)`。
- 产品GMV不筛订单状态和售后状态。
- 退款口径不参与本图表，仍由运营指标卡ADS按`订单状态='已关闭'`计算。
- 刷单阈值不变，仍为主订单任一子行`订单应付金额 >= 2000`。
- 产品分摊前正GMV总额为1,567,842.00元；分摊后公司产品GMV总额仍为1,567,842.00元，差额0.00元。

## 7. 推荐图表与ADS粒度

- 图表：横向降序条形图或矩形树图。
- 层级：`large_product_category -> product_category_l2 -> product_name`。
- 指标：`SUM(gmv_amount)`，显示占比。
- 公共筛选器：公司、日期、平台、店铺。
- ADS粒度：`统计日期 + 平台 + 公司 + 店铺 + 一级分类 + 二级分类 + 公司产品名称`。
- 平台商品ID和选购商品名称不进入最终产品维度。
