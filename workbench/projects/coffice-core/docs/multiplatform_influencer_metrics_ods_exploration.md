# 多平台达人指标 ODS 探查报告

## 1. 业务目标

在现有抖音达人指标基础上，补充视频号、京东、快手、小红书、拼多多和天猫的达人总量、达人GMV、达人退款金额和达人退款率。

- 有达人来源的平台：抖音、视频号、快手、天猫。
- 京东、小红书、拼多多没有达人来源，本轮仍按平台、公司、店铺和订单自然日生成金额为0的记录，供DataEase平台、日期、公司和店铺筛选器联动。
- 本报告只锁定本轮四项指标；现有月度10万+达人、月GMV Top5和商务目标达成表是否扩展到新平台，不在本轮已确认范围内。

## 5. 天猫达人识别和金额候选

天猫ODS一行一个订单，没有达人ID，也没有商品单价字段。当前以商品标题匹配全角方括号：

```text
【xxx专属】
【xxx推荐】
```

当前3,192个订单中有94个命中，原始提取名称有3个：

| 原始提取名称 | 标记 | 行数 | 示例 |
| --- | --- | ---: | --- |
| `加购！胡可` | 推荐 | 42 | `【加购！胡可推荐】...` |
| `胡可` | 推荐 | 20 | `【胡可推荐】...` |
| `芳芳` | 专属 | 32 | `...,【芳芳专属】...` |

用户已确认把开头营销词`加购！`去除，`【加购！胡可推荐】`和`【胡可推荐】`统一为达人“胡可”，因此当前天猫活跃达人为2人。天猫没有源达人ID，规范名称通过`dim.dim_influencer_business_assignment_monthly`查得稳定ID：蜜蜂欢乐社`1111111`、蜜蜂心愿社`2222222`、胡可`3333333`、芳芳`4444444`；当前订单只命中胡可和芳芳。

94个达人订单均没有`买家应付货款>2000`的刷单。订单状态分布为：交易成功67行、交易关闭24行、卖家已发货3行；24个交易关闭订单都有非零源退款金额。

天猫没有与其他平台完全等价的`商品单价`，按现有字段可形成以下候选：

| GMV候选 | GMV | 交易关闭退款 | 退款率 | 说明 |
| --- | ---: | ---: | ---: | --- |
| `总金额` | 25,962.00 | 7,179.00 | 27.65% | 原始商品总价；多件订单会乘数量 |
| `总金额 ÷ 宝贝总数量` | 21,346.10 | 6,139.00 | 28.76% | 最接近既有“商品单价一行、不乘数量”口径；94行数量均可解析，21行为多件 |
| `买家应付货款`（最终确认） | 14,549.01 | 4,409.00 | 30.30% | 用户最终确认的天猫达人GMV；交易关闭时同一金额计退款 |
| `买家实付金额` | 10,580.01 | 440.00 | 4.16% | 已受退款影响，交易关闭订单大多为0，不适合作为本指标退款基数 |

刷单判断固定使用`买家应付货款>2000`并按订单整单排除；GMV直接取`买家应付货款`，退款固定取`订单状态='交易关闭'`时的同一买家应付货款，不直接使用源`退款金额`。

## 6. 京东、小红书和拼多多补零设计

三个无达人平台不能只在最终汇总时硬编码一条静态0，否则日期和店铺筛选后会丢失。建议仍从各自ODS建立本指标独立DWD，再在平台DWS按`平台+店铺+订单自然日`生成一个占位达人行：

```text
influencer_id   = __no_influencer__
influencer_name = 无达人
gmv_amount      = 0
refund_amount   = 0
refund_rate     = 0
```

达人总量必须使用`COUNT(DISTINCT CASE WHEN gmv_amount > 0 THEN influencer_key END)`，所以占位行不会被计为达人。月Top5、10万+和商务归属若后续扩展，必须排除占位ID。

| 京东 | 11 | 2026-06-25至2026-07-05 |

## 7. 数据质量和抽样结论

- 视频号、快手、天猫的订单号和统计日期均无缺失。
- 视频号抽样的取消订单`3737547598384493312`：达人`wx24e83758a23f2e43 / 朱迪会吃饭`，单件价格198元，候选GMV与退款均计198元。
- 快手抽样的关闭订单`2616800401373645`：达人`1504691 / 阿聪💄`，商品单价198元，候选GMV与退款均计198元。
- 天猫抽样的关闭订单`3303036194731018872`：标题`【加购！胡可推荐】...`，数量1，总金额260元、买家应付149元、买家实付0元、源退款149元，证明`买家实付金额`不能还原同口径退款。
- 天猫抽样的关闭订单`3303785715567017797`：数量2、总金额520元、买家应付370元，证明直接使用总金额和还原单价会产生结果差异。
- 快手同一达人ID在不同日期存在昵称变化，活跃达人数和GMV必须按ID合并，不能按昵称拆分。

## 8. 已确认决策

1. 天猫达人GMV最终改为直接使用`买家应付货款`，当前GMV 14,549.01元。
2. 天猫退款为`订单状态='交易关闭'`订单的同口径买家应付货款，当前退款4,409.00元、退款率30.30%。
3. `【加购！胡可推荐】`与`【胡可推荐】`统一为达人“胡可”。
4. 天猫达人ID从月度达人归属表按规范名称唯一查得；业务归属仍按不晚于指标月份的最新版本生效。
5. 京东、小红书和拼多多按平台、标准店铺和订单自然日补0，占位ID不进入达人总量、月排名或商务活跃达人数。

口径已经锁定，已进入独立DWD/DWS和共享ADS指标加工。
